Lifespace

Lifespace is a personal dashboard for organizing everyday tasks, projects, shopping, health routines, and spiritual growth. Its Google Tasks connection displays the owner's existing lists in selected dashboard widgets and keeps task changes synchronized.

This page provides information about the app. The dashboard is hosted separately on the owner's private server and requires private-network access and an authorized Google sign-in to display connected tasks.

Personal use

Lifespace is configured for its owner's personal use. The public information page does not provide access to the private dashboard or invite new dashboard accounts.
