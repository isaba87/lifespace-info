Lifespace privacy policy

Effective date: September 15, 2026.

Lifespace requests Google account identity information to confirm the authorized owner, and Google Tasks permission to read lists and tasks and save changes the owner makes in the dashboard. The integration uses task titles, notes, due dates, completion status, list identifiers, and parent-task relationships.

Task data and widget placements are stored on the owner's server so the same information is available across the owner's devices. Google authorization tokens are encrypted before being saved on that server. Access to connected task data requires an owner session.

Lifespace uses this data to provide the dashboard and task synchronization. It does not sell Google user data, use it for advertising, or use it to train artificial-intelligence models. Changes made to tasks in Lifespace are sent to Google Tasks to keep the connected lists current.

The owner can disconnect Google Tasks from the dashboard. This removes the app's saved connection and cached task snapshot; widget placements remain. Disconnecting does not delete the original tasks in Google. The owner can separately revoke Lifespace's access in Google Account settings. Server backups may retain earlier data until the owner removes those backups.

Lifespace's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This information page has no sign-in form and collects no task data. The website hosting provider may process ordinary web-request information when serving this page.
